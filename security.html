Security at SolverX

How we protect the simulation data, models and accounts our customers trust us with.

Compliance

  • We are undergoing a SOC 2 Type II audit by an independent audit firm. The observation period started on 30 September 2026.
  • Our information security policies are approved by management and reviewed annually. Employees are required to acknowledge them.

Hosting and data protection

  • The SolverX platform runs on Microsoft Azure in the Korea Central (Seoul) region.
  • All traffic to SolverX services is served over HTTPS (TLS). Storage accounts accept HTTPS only and do not allow public blob access.
  • Data at rest is encrypted by Azure's platform encryption for databases and storage.
  • The production database is not reachable from the public internet. It runs zone-redundant high availability, with automatic backups kept for 30 days in geo-redundant storage.

Access control

  • Access to production systems is limited to authorized engineers on a least-privilege basis.
  • We review access to critical systems every quarter and remove access when someone leaves the company.
  • Secrets and signing keys are stored in Azure Key Vault.

Secure development

  • Code changes go through pull requests. Protected branches require a peer review before merge.
  • Automated checks run on pull requests, including secret scanning.
  • Dependencies are scanned automatically for known vulnerabilities.

Monitoring and incident response

  • Microsoft Defender for Cloud protects our production subscription. Cloud activity logs and network flow logs are collected centrally.
  • Our public services are checked every 10 minutes, and current availability is published on our status page.
  • We follow a documented incident response plan and notify affected customers of security incidents as our agreements require.

Report a security issue

If you believe you have found a vulnerability in SolverX, email support@solverx.ai with the details. Please give us reasonable time to investigate before disclosing it publicly.
